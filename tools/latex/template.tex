{\centering\large\scshape Before you begin\par}\vspace{6mm}
\noindent\textbf{Do not read this book from the first page to the last.} It will not make sense, and it will not be your story.

You are the main character. Read until you reach a choice. Each choice tells you which page to turn to; go there and carry on reading from the top of that page. Some choices are only open to you if you have a particular codeword. If you don't have it, that path is closed to you this time.

Your choices are remembered. When the book tells you to write down a \textbf{codeword}, write it on the codeword sheet overleaf. Later pages will ask whether you have it. Be honest: the book can only remember what you write down.

%%SESSIONS%% When a session ends, the book tells you so, and tells you which page to turn to next. Write that page down as your bookmark.
