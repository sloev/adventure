# 1-bit print master

`halftone.c` is copied unchanged from [sloev/grudgebook](https://github.com/sloev/grudgebook) `tools/halftone.c` (commit a9b9939). `onebit.py` ports `dot_threshold()` and `dot_gain_inverse()` from that repository's `tools/halftone.py` and applies them to whole book pages. See the docstring in `onebit.py` for what is and isn't applied, and why.
